① 수열의 극한
\(\lim_{n\to\infty}a_n=L\)이면 \(n\)이 커질수록 \(a_n\)이 \(L\)에 가까워진다는 뜻이다.
② 급수와 부분합
\(\sum_{n=1}^{\infty}a_n\)은 먼저 \(S_N=\sum_{n=1}^{N}a_n\)을 만든 뒤 \(N\to\infty\)의 극한을 본다.
③ 등비급수
\(\sum_{n=0}^{\infty}ar^n=\frac{a}{1-r}\), 단 \(|r|<1\). 끝점에서는 반드시 따로 확인한다.
④ 비교판정
\(0\le a_n\le b_n\)이고 \(\sum b_n\)이 수렴하면 \(\sum a_n\)도 수렴한다.
⑤ 비율판정법
\(L=\lim\left|\frac{a_{n+1}}{a_n}\right|\). \(L<1\)이면 수렴, \(L>1\)이면 발산한다.
⑥ 절대수렴
\(\sum|a_n|\)이 수렴하면 원래 급수 \(\sum a_n\)도 반드시 수렴한다.
⑦ 거듭제곱급수
\(\sum c_n(x-a)^n\)에서 먼저 반지름 \(R\)을 구하고, 그다음 양 끝점을 따로 검사한다.
⑧ Taylor / Maclaurin
\(f(x)=\sum_{n=0}^{\infty}\frac{f^{(n)}(c)}{n!}(x-c)^n\). \(c=0\)이면 Maclaurin 급수이다.
⭐ 가장 중요한 습관: 수렴반지름만 구하고 끝내면 안 된다. 끝점 검사까지 해야 최종 수렴구간이 완성된다.

01수열의 처음 다섯째 항
🔎 더 자세한 풀이 포인트

일반항에 값을 대입하는 문제에서는 먼저 괄호와 지수의 범위를 정확히 읽는다. 특히 \(\sin(n\pi/2)\)은 \(n=1,2,3,4,5\)에서 \(1,0,-1,0,1\)이 반복되므로 삼각함수의 기본각 값을 먼저 확인한다.

개념: 수열의 일반항에 n=1,2,3,4,5를 차례로 대입하면 된다.
\((1) a_{n} = sin(\frac{nπ}{2}) / n\)

n=1,2,3,4,5를 차례로 대입한다.

\(a_{1} = sin(\frac{π}{2}) = 1\)

\(a_{2} = sin(π)/2 = 0\)

\(a_{3} = sin(\frac{3π}{2})/3 = −\frac{1}{3}\)

\(a_{4} = sin(2π)/4 = 0\)

\(a_{5} = sin(\frac{5π}{2})/5 = \frac{1}{5}\)

답: \(1, 0, −\frac{1}{3}, 0, \frac{1}{5}\)
\((2) a_{n} = (−π)n / 4n\)

분모와 분자를 각각 n제곱으로 묶으면 a_{n}=(−π/4)ⁿ이다.

답: \(−\frac{π}{4}, \frac{π2}{16}, −\frac{π3}{64}, \frac{π4}{256}, −\frac{π5}{1024}\)
\((3) a_{n} = ln n / n\)
답: \(0, \frac{ln2}{2}, \frac{ln3}{3}, \frac{ln4}{4}, \frac{ln5}{5}\)
\((4) a_{n} = (−1)n⁻1/(2n−1)\)
답: \(1, −\frac{1}{3}, \frac{1}{5}, −\frac{1}{7}, \frac{1}{9}\)
02수열의 수렴과 발산
🔎 더 자세한 풀이 포인트

수렴 여부는 하나의 유한한 값으로 가까워지는지를 본다. \(a_n\to\infty\)이면 발산하고, 짝수·홀수 항이 서로 다른 값으로 가면 발산한다. \(1/n\to0\), \(r^n\to0\ (|r|<1)\)은 자주 사용하는 기본 극한이다.

개념: 수열이 어떤 하나의 유한한 값으로 가까워지면 수렴한다. 한 값으로 가지 않거나 무한히 커지면 발산한다.
\((1) 2, 6, 10, 14, …, 4n−2, …\)

\(a_{n}=4n−2.\) n→∞이면 \(a_{n}→∞.\)

답: 발산
\((2) \frac{1}{2}, \frac{1}{4}, \frac{1}{6}, …, 1/(2n), …\)

\(a_{n}=1/(2n).\) 분모가 무한히 커지므로 \(a_{n}→0.\)

답: 수렴, 극한 0
\((3) 2, 0, 2, 0, …\)

홀수 번째 항은 2, 짝수 번째 항은 0이므로 하나의 값으로 가까워지지 않는다.

답: 발산
\((4) 1, −\frac{1}{3}, \frac{1}{5}, −\frac{1}{7}, …\)

\(a_{n}=(−1)n⁻1/(2n−1).\) 부호는 번갈아 바뀌지만 크기는 0으로 간다.

답: 수렴, 극한 0
\((5) 2−1, 2−\frac{1}{2}, 2−\frac{1}{3}, …\)

\(a_{n}=2−\frac{1}{n}.\) 1/n→0이므로 \(a_{n}→2.\)

답: 수렴, 극한 2
\((6) 1, \frac{1}{2}, \frac{1}{4}, …, \frac{1}{2n}⁻1\)

공비가 1/2인 수열의 항이므로 \((\frac{1}{2})n⁻1→0.\)

답: 수렴, 극한 0
\((7) 2, \frac{4}{3}, \frac{10}{9}, …, 1+(\frac{1}{3})n⁻1\)

a_{n}=1+(1/3)ⁿ⁻¹이고 \((\frac{1}{3})n⁻1→0.\)

답: 수렴, 극한 1
\((8) 5,5,5,…\)

모든 항이 5이다.

답: 수렴, 극한 5
03수열의 극한
🔎 더 자세한 풀이 포인트

유리식은 최고차항으로 나누고, \(1/n\), \(1/n^2\)처럼 0이 되는 항을 정리한다. 루트가 있는 차는 유리화하여 비교한다. \((-1)^n\)이 있어도 절댓값이 0으로 가면 샌드위치 정리로 극한을 구할 수 있다.

핵심: 분수식은 최고차항을 이용하고, √가 있는 식은 유리화하면 편하다.
\((1) \frac{3n2+4n−1}{n^{2}+n+2}\)

분자와 분모를 n²으로 나눈다.

\(\frac{3+\frac{4}{n}−\frac{1}{n^{2}}}{1+\frac{1}{n}+\frac{2}{n^{2}}} → 3.\)

답: 3
\((2) \sqrt{n^{2}+2n}−n\)

유리화하면

\(2n / (\sqrt{n^{2}+2n}+n) = 2 / (\sqrt{1+\frac{2}{n}}+1).\)

n→∞이면 분모는 2가 된다.

답: 1
\((3) (−1)\frac{n}{n}\)

|(−1)ⁿ/n|=1/n→0이므로 원래 수열도 0으로 간다.

답: 0
\((4) (−1)n(n+1)/n^{2}\)

\((n+1)/n^{2}=\frac{1}{n}+\frac{1}{n^{2}}→0.\)

답: 0
\((5) ln \frac{n}{e^{n}}\)

지수함수 eⁿ이 로그 ln n보다 훨씬 빠르게 증가하므로 비율/로피탈 관점에서 극한은 \(0.\)

답: 0
\((6) ln \frac{n}{n}\)

n이 ln n보다 빠르게 증가한다.

답: 0
\((7) \frac{2sinnθ−4cosnθ}{3sinnθ+2cosnθ}, 0<θ<\frac{π}{4}\)

이 범위에서는 sinθ<cosθ이므로 cosⁿθ로 나눈다.

\(\frac{(2tannθ)−4}{3tannθ+2}.\) 0<tanθ<1이므로 \(tannθ→0.\)

답: \(−2\)
\((8)\) 같은 식, \(\frac{π}{4}<θ<\frac{π}{2}\)

이번에는 sinθ>cosθ이므로 sinⁿθ로 나눈다.

\(\frac{2−4cotnθ}{3+2cotnθ}.\) 0<cotθ<1이므로 \(cotnθ→0.\)

답: \(\frac{2}{3}\)
04수열의 처음 네 항과 단조수렴정리
🔎 더 자세한 풀이 포인트

단조수렴정리는 '단조 + 유계'가 핵심이다. 증가하는지 감소하는지 확인하고 상한 또는 하한을 증명한 뒤 수렴을 결론낸다. 마지막에는 극한을 \(L\)이라 놓고 재귀식에 대입한다.

단조수렴정리: 단조증가하면서 위로 유계이면 수렴하고, 단조감소하면서 아래로 유계이면 수렴한다.
\((1) a_{n}=(4n−3)/2n\)

n=1,2,3,4를 대입한다.

\(a_{1}=\frac{1}{2}, a_{2}=\frac{5}{4}, a_{3}=\frac{9}{8}, a_{4}=\frac{13}{16}.\)

따라서 처음 네 항은 \(\frac{1}{2}, \frac{5}{4}, \frac{9}{8}, \frac{13}{16}.\)

또한 분자는 n에 비례하지만 분모는 2ⁿ으로 지수적으로 증가하므로 \(a_{n}→0.\) 따라서 수렴한다.

답: \(\frac{1}{2}, \frac{5}{4}, \frac{9}{8}, \frac{13}{16}; 수렴\)
\((2) a_{n}₊_{1}=1+(\frac{1}{2})a_{n}, a_{1}=1\)

\(a_{2}=1+(\frac{1}{2})(1)=\frac{3}{2}.\)

\(a_{3}=1+(\frac{1}{2})(\frac{3}{2})=\frac{7}{4}.\)

\(a_{4}=1+(\frac{1}{2})(\frac{7}{4})=\frac{15}{8}.\)

따라서 \(1, \frac{3}{2}, \frac{7}{4}, \frac{15}{8}.\)

단조증가: \(a_{n}₊_{1}−a_{n}=1−a_{n}/2=(2−a_{n})/2.\) 아래의 유계성을 이용하면 a_{n}<2이므로 차이는 양수이다.

위로 유계: a_{1}=1<2이고 a_{n}<2라고 가정하면 \(a_{n}₊_{1}=1+a_{n}/2<2.\) 따라서 모든 n에서 \(a_{n}<2.\)

즉 단조증가 + 위로 유계이므로 수렴한다.

극한을 L이라 하면 \(L=1+\frac{L}{2},\) 따라서 \(L=2.\)

답: \(1, \frac{3}{2}, \frac{7}{4}, \frac{15}{8}; 단조증가·위로 유계이므로 수렴, 극한 2\)
05샌드위치 정리를 이용한 수렴성
🔎 더 자세한 풀이 포인트

샌드위치 정리는 직접 계산하기 어려운 항을 양쪽에서 눌러주는 방법이다. \(-b_n\le a_n\le b_n\)이고 \(b_n\to0\)이면 \(a_n\to0\)이다.

샌드위치 정리: A_{n}≤B_{n}≤C_{n}이고 A_{n}과 C_{n}이 같은 극한 L로 가면 B_{n}도 L로 간다.

주어진 부등식:

\(1/(\sqrt{n+2}+\sqrt{n+3}) < a_{n} < 1/(\sqrt{n+1}+\sqrt{n+2}).\)

유리화하면

\(1/(\sqrt{k+2}+\sqrt{k+3})=\sqrt{k+3}−\sqrt{k+2},\)

\(1/(\sqrt{k+1}+\sqrt{k+2})=\sqrt{k+2}−\sqrt{k+1}.\)

따라서 합하면 중간항이 소거되어

\(\sqrt{n+3}−\sqrt{3} < Σaₖ < \sqrt{n+2}−\sqrt{2}.\)

양변을 √(n+1)로 나누면

\((\sqrt{n+3}−\sqrt{3})/\sqrt{n+1} < (Σaₖ)/\sqrt{n+1} < (\sqrt{n+2}−\sqrt{2})/\sqrt{n+1}.\)

양쪽 극한이 모두 1이므로 샌드위치 정리에 의해 가운데도 1.

답: 1
06부분수열의 수렴성
🔎 더 자세한 풀이 포인트

부분수열은 원래 수열에서 특정 규칙으로 항만 고른 것이다. 원래 수열이 수렴하면 모든 부분수열은 같은 극한을 가져야 한다. 서로 다른 부분수열의 극한이 다르면 원래 수열은 발산한다.

부분수열: 원래 수열에서 특정한 번호의 항만 골라 만든 수열이다.

\(a_{n}=sin(\frac{nπ}{2}).\)

홀수 번째 항

\(a_{2}_{n}₋_{1}=sin((2n−1)\frac{π}{2})=1,−1,1,−1,…\)

두 값 사이를 계속 오가므로 하나의 극한이 없다.

\({2n−1}\) 부분수열: 발산
짝수 번째 항

\(a_{2}_{n}=sin(nπ)=0.\)

{2n} 부분수열: 0으로 수렴
07비에타 정리를 이용한 극한
🔎 더 자세한 풀이 포인트

비에타 정리는 다항방정식의 근의 합과 곱을 계수와 연결한다. 근을 직접 구하지 않고도 필요한 대칭식의 값을 구할 수 있다는 점이 핵심이다.

비에타 정리: x²+Bx+C=0의 두 근을 α,β라 하면 α+β=−B, αβ=C.

f(x)=x²+4nx−1=0의 두 근을 a_{n},b_{n}라 하자.

그러면 \(a_{n}+b_{n}=−4n, a_{n}b_{n}=−1.\)

구하려는 분자는

\(a_{n}2+b_{n}2=(a_{n}+b_{n})2−2a_{n}b_{n}\)

\(=16n2+2.\)

분모 \(f(n)=n^{2}+4n−1.\)

따라서 극한은 \(\frac{16n2+2}{n^{2}+4n−1}.\) 분자와 분모를 n²으로 나누면 \(16/(1)=16.\)

답: 16
084의 배수가 아닌 자연수의 합
🔎 더 자세한 풀이 포인트

조건이 붙은 자연수의 합은 전체에서 제외되는 항을 빼는 방식이 편하다. 특히 '4의 배수가 아닌 수'는 전체 합에서 4의 배수 합을 빼는 구조로 생각한다.

아이디어: 전체 합에서 4의 배수들의 합을 빼면 된다.

1부터 4n까지의 전체 합:

\(S_{n}=(4n)(4n+1)/2=8n2+2n.\)

4의 배수의 합:

\(4+8+…+4n=4(1+2+…+n)=4·n(n+1)/2=2n2+2n.\)

따라서 4의 배수가 아닌 자연수의 합:

\(T_{n}=(8n2+2n)−(2n2+2n)=6n2.\)

그러므로 \(T_{n}/S_{n}=6n2/(8n2+2n)→\frac{6}{8}.\)

답: \(\frac{3}{4}\)
09원과 직선의 교점 좌표
🔎 더 자세한 풀이 포인트

원과 직선의 교점은 직선식을 원의 방정식에 대입하여 이차방정식으로 만든다. 두 해를 구한 뒤 직선식에 다시 넣어 좌표를 완성한다.

핵심: 교점의 x좌표를 구하려면 해당 직선의 y값을 원의 방정식에 대입한다.

원: \(x^{2}+y2=4n2.\)

첫 번째 점 a_{n}

x축과 만나는 점이므로 \(y=0.\)

\(x^{2}=4n2 → x=±2n.\) 양의 x좌표이므로 \(a_{n}=2n.\)

두 번째 점 b_{n}

직선 y=√(4n)=2√n을 원에 대입:

\(x^{2}+4n=4n2 → x^{2}=4n2−4n.\)

양의 x좌표이므로 \(b_{n}=2\sqrt{n^{2}−n}.\)

따라서 \(a_{n}−b_{n}=2n−2\sqrt{n^{2}−n}.\)

n으로 묶으면 \(2n[1−\sqrt{1−\frac{1}{n}}].\) 유리화하면

\(2n·[\frac{\frac{1}{n}}{1+\sqrt{1−\frac{1}{n}}}]=2/[1+\sqrt{1−\frac{1}{n}}]→1.\)

답: 1
10부분합으로부터 무한급수의 합
🔎 더 자세한 풀이 포인트

무한급수는 직접 더하는 것이 아니라 부분합 \(S_N\)을 구하고 \(N\to\infty\)의 극한을 본다. 망원급수에서는 중간 항이 소거되는 구조를 찾는다.

핵심: S_{n}=a_{1}+…+a_{n}이라면 Σa_{n}=lim S_{n} (극한이 존재할 때)이다.
\((1) S_{n}=\frac{3n−2}{4n+1}\)

최고차항으로 비교하면 lim \(S_{n}=\frac{3}{4}.\)

답: \(\frac{3}{4}\)
\((2) S_{n}=2−(\frac{1}{5})n\)

(1/5)ⁿ→0이므로 lim \(S_{n}=2.\)

답: 2
\((3)\)

\(S_{n}=\frac{1}{2}[(1−\frac{1}{2})+(\frac{1}{2}−\frac{1}{3})+…+(\frac{1}{n}−1/(n+1))].\)

중간항이 모두 소거되어 \(S_{n}=\frac{1}{2}(1−1/(n+1)).\)

답: \(\frac{1}{2}\)
\((4)\)

로그의 합을 하나의 로그로 묶는다.

\(S_{n}=log[\frac{2·2}{1·3} · \frac{3·3}{2·4} · … · (n·n)/((n−1)(n+1))].\)

중간 인수들이 약분되어 \(S_{n}=log(2n/(n+1)).\)

n→∞이면 \(2n/(n+1)→2.\)

답: log 2
11무한급수의 합
🔎 더 자세한 풀이 포인트

등비급수는 첫항과 공비를 정확히 찾아 \(a/(1-r)\)를 적용한다. 망원급수는 항을 차이로 분해해 부분합에서 소거되는 항을 확인한다.

핵심: 등비급수, 망원급수, 삼각함수의 값 등을 구분한다.
\((1)\)

\(2Σ(\frac{1}{2})ᵏ+3Σ(\frac{1}{3})ᵏ.\) 첫 번째는 \(2·[\frac{\frac{1}{2}}{\frac{1}{2}}]=2,\) 두 번째는 \(3·[\frac{\frac{1}{3}}{\frac{2}{3}}]=\frac{3}{2}.\)

답: \(\frac{7}{2}\)
\((2)\)

Σ(1/k−1/(k+1))은 망원급수. 부분합은 \(1−1/(n+1)→1.\)

12두 무한급수의 합 관계
🔎 더 자세한 풀이 포인트

주어진 관계식에서는 보정항의 합을 먼저 계산한다. \(1/[n(n+1)]=1/n-1/(n+1)\)은 대표적인 망원급수이므로 반드시 기억한다.

핵심: 주어진 식에서 필요한 보정급수의 합을 먼저 계산한다.

주어진 식:

\(\sum [a_{n}−3/{n(n+1)}]=3.\)

그런데 1/[n(n+1)]=1/n−1/(n+1)이므로

\(\sum 3/[n(n+1)] = 3·Σ(\frac{1}{n}−1/(n+1))=3.\)

따라서 \(\sum a_{n}−3=3.\)

13등비수열의 짝수항·3의 배수항 합
🔎 더 자세한 풀이 포인트

전체 등비급수의 합을 \(S\)라고 두면 짝수항과 3의 배수항도 각각 등비급수가 된다. 각 합을 \(S,r\)로 나타낸 뒤 주어진 조건으로 미지수를 결정한다.

등비급수: a_{n}=arⁿ⁻¹, 전체합 S=a/(1−r).

전체 합을 S라고 하자.

짝수항 합은 \(ar+ar3+…=ar/(1−r2).\)

이를 S=a/(1−r)로 나타내면 \(Sr/(1+r)=3.\)

3의 배수항 합은 \(ar2+ar5+…=ar2/(1−r3)=Sr2/(1+r+r2)=\frac{12}{13}.\)

첫 식에서 \(S=3(1+r)/r.\)

이를 두 번째 식에 대입하면

\(3r(1+r)/(1+r+r2)=\frac{12}{13}.\)

정리하면 \(39r+39r2=12+12r+12r2,\) 즉 \(27r2+27r−12=0.\)

3으로 나누면 \(9r2+9r−4=0.\)

인수분해하면 \((3r−1)(3r+4)=0.\)

\(r=\frac{1}{3}\) 또는 \(r=−\frac{4}{3}.\) 무한등비급수는 |r|<1이어야 하므로 r=1/3만 가능.

\(S=3\frac{1+\frac{1}{3}}{\frac{1}{3}}=12.\)

Maclaurin: 중심 c=0인 Taylor 급수. 도함수 값이 반복되는 함수는 매우 쉽게 전개된다.
\((1) cos x\)

도함수 순서: cos \(x, −sin x, −cos x,\) sin x가 반복된다.

0에서의 값은 \(1,0,−1,0,….\)

\(\cos x=1−\frac{x^{2}}{2!}+\frac{x^{4}}{4!}−…=Σ(−1)nx2n/(2n)!\)
\((2) cosh x\)

\(cosh\) x의 도함수는 \(sinh x,\) 다시 \(cosh\) x로 반복된다. 0에서 \(cosh0=1, sinh0=0.\)

\(cosh x=1+\frac{x^{2}}{2!}+\frac{x^{4}}{4!}+…=Σx2n/(2n)!\)
241/√(4−x)의 Maclaurin 급수

먼저 \(4-x=4(1-x/4)\)로 바꿔 표준 이항급수 형태를 만든다. \(t=x/4\)를 대입하고 바깥의 \(1/2\)를 마지막까지 곱한다.

이항급수: (1−t)^−1/2=1+(1/2)t+(3/8)t²+(5/16)t³+….

4−x=4(1−x/4)이므로

\(1/\sqrt{4−x}=1/[2\sqrt{1−\frac{x}{4}}]=(\frac{1}{2})(1−\frac{x}{4})^−\frac{1}{2}.\)

t=x/4를 이항급수에 넣는다.

\((\frac{1}{2})[1+(\frac{1}{2})(\frac{x}{4})+(\frac{3}{8})(\frac{x}{4})2+(\frac{5}{16})(\frac{x}{4})3+…]\)

\(\frac{1}{2}+\frac{x}{16}+\frac{3x2}{256}+\frac{5x3}{2048}+\frac{35x4}{65536}+…\)

바로 적분하기 어려운 함수를 Taylor 급수로 전개하면 항별 적분이 가능하다. 필요한 정확도까지 항을 계산하고 마지막에 반올림한다.

핵심: cos(x²), e^(−x²)은 초등함수 형태의 간단한 원시함수가 없으므로 수치적분 또는 급수 전개를 이용한다.
\((1) ∫₀1 cos(x^{2}) dx\)

\(cos(x^{2})=1−\frac{x^{4}}{2!}+\frac{x^{8}}{4!}−….\)

항별 적분하면 1−1/(2·5)+1/(24·9)−…이고 수렴한다. 수치 계산 결과 약 \(0.9045242379.\)

답: 0.9045
\((2) ∫₀1 e^(−x^{2}) dx\)

\(e^(−x^{2})=1−x^{2}+\frac{x^{4}}{2!}−\frac{x^{6}}{3!}+….\)

항별 적분하거나 수치적분하면 약 0.7468241328.

답: 0.7468
26Taylor 근사를 이용한 sin 12°
🔎 더 자세한 풀이 포인트

삼각함수 Taylor 근사에서는 각도를 반드시 라디안으로 바꾼다. \(12^\circ=\pi/15\)을 구한 뒤 \(x-x^3/3!+x^5/5!\)에 항별로 대입한다.

중요: 삼각함수의 Taylor 급수에 넣는 각도는 반드시 라디안이다.

주어진 근사식:

\(\sin x ≈ x−\frac{x^{3}}{3!}+\frac{x^{5}}{5!}.\)

12°를 라디안으로 변환한다.

\(12°=\frac{12π}{180}=\frac{π}{15}≈0.20943951.\)

따라서

\(sin12°≈0.20943951−(0.20943951)\frac{3}{6}+(0.20943951)\frac{5}{120}.\)

계산하면 약 0.2079116943.

답: 소수점 이하 여섯째 자리까지 0.207912
